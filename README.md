# Tartibak AI 🤖📱

> A professional, AI-powered Android app categorization tool designed for Termux and Python environments, developed by **عبدالله العنزي (AFTH966)**.
> 
> أداة احترافية مدعومة بالذكاء الاصطناعي لتصنيف وتنظيم تطبيقات أندرويد مصممة خصيصاً للعمل في بيئة Termux.

---

## 🌟 Overview / نظرة عامة
**Tartibak AI** is a smart heuristic analysis tool that automatically classifies your installed Android applications into organized categories to keep your device clean, structured, and easy to manage.

أداة تحليل ذكية تقوم بتصنيف وتجميع تطبيقات الأندرويد المثبتة على جهازك تلقائياً في فئات منظمة، مما يبقي جهازك مرتباً وسهل الإدارة.

---

## 📂 Categories / الفئات الرئيسية
The tool analyzes apps and sorts them into five main categories:
تقوم الأداة بتحليل التطبيقات وفرزها إلى خمسة تصنيفات رئيسية:

1. **Games (الألعاب)**
2. **Social Media (التواصل الاجتماعي)**
3. **Media & Entertainment (الوسائط والترفيه)**
4. **Tools & Productivity (الأدوات والإنتاجية)**
5. **Shopping & Services (التسوق والخدمات)**

---

## 🚀 Installation & Usage / التثبيت والاستخدام

You can easily clone and run the tool in your Termux environment using the following commands:
يمكنك بسهولة نسخ وتشغيل الأداة في بيئة Termux الخاصة بك باستخدام الأوامر التالية:

```bash
# Clone the repository / استنساخ المستودع
git clone [https://github.com/AFTH966/tartibak-ai.git](https://github.com/AFTH966/tartibak-ai.git)

# Navigate into the project folder / الدخول إلى مجلد المشروع
cd tartibak-ai

# Run the tool / تشغيل الأداة
python3 tartibak_ai.py

📄 Output Report / تقرير المخرجات
​The tool generates a detailed JSON report (tartibak_ai_report.json) containing the classified application data for review and automated tracking.
​تُنشئ الأداة تقريراً مفصلاً بصيغة JSON باسم (tartibak_ai_report.json) يضم بيانات التطبيقات المصنفة للمراجعة والتتبع التلقائي.
